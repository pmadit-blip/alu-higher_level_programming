# Python Object Relational Mapping

## Overview
This directory contains Python scripts that interact with MySQL databases
using MySQLdb and SQLAlchemy ORM.

## Files

| File | Description |
|---|---|
| `0-select_states.py` | Lists all states from the database |

## How to Run

### 0-select_states.py
```bash
./0-select_states.py <mysql_username> <mysql_password> <database_name>
```

## Requirements

- Python 3.x
- MySQLdb
- MySQL server running on localhost at port 3306
